# VW 잡코리아 기업정보 — 채용공고 디자인 활용 자료

- 출처: [잡코리아 브이더블유 기업정보](https://www.jobkorea.co.kr/company/46851725)
- 확인일: 2026-09-26
- 확인 범위: 기업 기본정보, 연혁·수상, 기업소개, 복리후생, 기업위치, 사진 썸네일, 연결된 채용공고.
- 목적: 채용공고의 회사 소개·문화·신뢰 정보·시각 소재를 설계할 때 참고한다. 원문 전체의 복사본이 아닌 사실 요약과 디자인 적용안이다.
- 아래의 ‘페이지 확인 정보’와 ‘제안 문구·디자인 해석’을 구분한다. 이 문서 작성만으로 공고 이미지나 사이트 본문을 변경하지 않았다.

## 2. 기업 소개에서 읽을 수 있는 브랜드 철학

다음은 페이지의 회사 소개를 요약한 것이다.

- **원더랜드:** 더 나은 생각과 디자인이 더 따뜻한 디지털 세상으로 이어진다는 지향점.
- **함께:** 동료에서 고객·사회·세상으로 이어지는 관계를 중요하게 다룸.
- **아이디어와 사람:** 놀라운 발상 자체뿐 아니라 사람에 대한 이해와 배려를 가치로 삼음.
- **디지털 크리에이티브:** 브랜드의 생각을 디지털 경험과 시각적 표현으로 구현하는 사업 정체성.

브랜드 키워드로 페이지에 제시된 표현: `WITH`, `Wonder Idea`, `Think Human`, `V˚ WONDERLAND EXTENSION`.

### 사업분야 요약

- 기업·제품·브랜드 웹사이트
- 브랜드 아이덴티티와 커뮤니케이션 전략
- 홍보·프로모션
- 크리에이티브 그래픽 디자인
- PR 인터랙티브 모션 영상
- 모바일 GUI·서비스 디자인
- 디지털 서비스

이는 회사의 사업 범위다. 디자이너 한 명이 모든 사업을 담당한다는 뜻으로 채용 업무를 확장하지 않는다.

## 3. 복리후생 — 공고에 옮길 수 있는 항목

| 묶음 | 페이지 확인 내용 | 표현 시 유의점 |
| --- | --- | --- |
| 보험·노후 | 4대보험, 퇴직연금 | 기본정보의 국민연금과 복리후생의 퇴직연금을 구분 |
| 휴가·휴무 | 연차, 반차, 경조휴가, 노동절 휴무 | 추가 휴가 일수를 추정하지 않음 |
| 문화 | 자유로운 휴가문화 | 무제한 휴가·승인 없는 휴가로 바꾸지 않음 |
| 지원 | 경조금, 장비 지원 | 지급액·장비 종류·지급 주기 미확인 |
| 편의 | 음료·간식 제공 | 식사 제공·식비 지원으로 확대하지 않음 |

재택근무, 유연출퇴근의 구체적 범위, 교육비, 야근수당, 식대 등은 이 기업정보 페이지에서 확인하지 못했다. 다른 공고나 별도 승인 자료의 조건과 혼동하지 않는다.

## 4. 사진·이미지 활용

페이지 상단에서 ‘내부’, ‘사무실내부’, ‘카페테리아’, ‘사무실내부’로 소개된 사진 4개를 확인했다. 썸네일에는 식물, 목재 수납장, 따뜻한 조명과 실내 공간이 보인다.

### 디자인 해석

- 실제 공간의 따뜻한 재질과 식물은 ‘사람을 생각하는 회사’라는 소개와 연결하기 좋다.
- 흑백 중심 브랜드 레이아웃에 자연스러운 목재·조명 색을 살린 실사 사진을 사용하면 차가운 추상 이미지만 사용할 때보다 생활감을 전달할 수 있다.
- 회사 소개에는 ‘브랜드 관점’, 복지에는 ‘실제 생활 공간’을 배치해 두 이미지의 역할을 나눈다.

### 사용 전 확인

2025.11 성산동 이전이 연혁에 기재되어 있다. 사진의 촬영일·촬영 장소는 확인되지 않았으므로 현재 성산동 사무실 사진이라고 단정하지 않는다. 실제 적용 시 회사 보유 원본과 현재 공간 여부를 확인한다. 이번 작업에서는 원격 사진을 내려받거나 프로젝트에 추가하지 않았다.

페이지의 잡코리아 파란색 UI는 플랫폼의 색상이다. VW의 브랜드 컬러로 해석하지 않는다. 회사 컬러는 기존 프로젝트에서 정한 차콜·아이보리 중심 기준과 공식 홈페이지를 따른다.

## 5. 공고용 제안 문구

아래는 원문 인용이 아닌 재작성 초안이다. 채용 사실을 추가하는 문구가 아니라 기업 철학을 전달하는 문구로 사용한다.

### 짧은 회사 소개

> 사람을 이해하는 생각에서, 더 나은 디지털 경험이 시작됩니다. 브이더블유는 브랜드와 사람을 연결하는 디자인으로 더 따뜻한 디지털 세상을 만들어갑니다.

### 제목 후보

- 좋은 생각이, 더 나은 경험으로.
- 사람을 생각하고, 가능성을 디자인합니다.
- 함께 만드는 우리의 원더랜드.

### 문화 소개

> 동료와 함께 생각하고, 고객과 함께 방향을 찾습니다. 사람을 배려하는 아이디어를 디지털 경험으로 만드는 팀입니다.

### 복지 소개

> 연차·반차와 자유로운 휴가문화, 경조휴가와 경조금, 업무 장비 지원, 음료와 간식 제공. 일상에 필요한 지원을 함께 준비합니다.

문구 길이는 최종 PNG 기준으로 조정한다. 각종 지원을 과장하거나 상세 조건이 확인되지 않은 혜택을 추가하지 않는다.

## 6. 디자인별 적용 제안

| 시안 | 적용 위치 | 표현 방식 |
| --- | --- | --- |
| A 에디토리얼 | 회사 소개·회사 생활 | 짧은 한글 철학 문장과 실제 공간 사진. 본문 여백과 차분한 순서 유지 |
| B 타이포 포스터 | 히어로 다음 소개·자격요건 전환 | 사람과 아이디어를 뜻하는 짧은 키워드, 수상 사례를 절제된 목록으로 제시 |
| C 브랜드 프레임 | 관점 소개·중간 이미지·복지 영역 | 추상 이미지는 가능성과 감각, 실사 사진은 실제 근무환경을 담당. 따뜻한 재질과 자연광 활용 |

### 추천 정보 순서

1. 어떤 디자이너를 찾는가 — 직무·경력.
2. 어떤 회사인가 — 사람 중심의 아이디어와 디지털 경험.
3. 어떤 일을 하는가 — 해당 공고의 실제 담당업무.
4. 무엇을 만들어왔는가 — 검증된 대표 수상 사례.
5. 어떻게 일하는가 — 현재 공간과 확인된 복지.
6. 어떻게 지원하는가 — 제출 자료와 지원 방법.

모든 정보를 한 장에 넣기보다 회사 소개 1문단, 신뢰 정보 2~3개, 복지 3~4개 묶음으로 편집한다. 재무·대표자·관심기업 수는 채용 디자인의 필수 요소가 아니다.

## 7. 현재 프로젝트와의 연결·우선순위

- 9월 26일 디자이너 공고의 제출 자료는 사용자 지시에 따라 **이력서·포트폴리오**, **희망연봉은 이력서에 필수 기재**다. 기업소개 자료를 참고하다 경력기술서를 다시 추가하지 않는다.
- 페이지의 채용 목록에는 2026.09.10~2026.10.16 디자이너 및 PM/기획자 공고 2개가 표시되어 있다. 프로젝트의 9월 26일 테스트 회차를 실제 잡코리아 신규 등록 사실로 취급하지 않는다.
- 접수기간은 목록·잡코리아 접수기간 영역에서 관리하고 게시 PNG에는 넣지 않는다.
- 기존에 배포된 루트 `VW-*.png` 8개는 보존한다. 이미지 수정은 공고 ID별 폴더의 생성 파일에 반영한다.
- 공고별 조건은 사용자의 최신 승인 내용과 해당 회차 원문을 우선한다. 이 자료는 회사 소개를 보강하는 참고 자료다.
- 출처의 기업구분과 법인전환 연혁이 충돌하므로 법적 형태를 새 강조 문구로 추가하지 않는다.

## 8. 게시 전 확인할 항목

- 사원수 22명과 현행 기업 형태
- 사진이 현재 성산동 사무실인지 여부와 원본 파일
- 경조금·장비 지원의 현행 운영 여부
- 해외 거점의 현재 운영 여부 — 사용할 때만 확인
- 수상 명칭·연도·프로젝트 — 수상 정보를 넣을 때 확인
- 이미지의 가독성, 한글 어절·역명 줄바꿈
