# C · 브랜드 프레임 — 디자인 컨셉 v1

현재 적용 버전은 [v2 이미지 중심 캠페인](C-brand-frame-v2.md)이다. 아래는 v1 보관 기록이다.

기준일: 2026-09-26. 적용 공고: `2026-09-26-designer`. 컨셉 ID: `brand-frame-v1`.

## 홈페이지에서 가져온 원칙

[VW 공식 홈페이지](https://www.v-w.co.kr/)를 2026-09-26에 직접 살펴보았다. 흰 배경과 검은 산세리프, 대형 글자, 비대칭 여백, 회전해 겹쳐진 프로젝트 이미지, 작은 원형 표시가 주요 시각 요소다. 브랜드를 이해하고 구조와 감성을 함께 고민한다는 소개를 새 관점을 만드는 디자이너의 초대로 해석했다.

홈페이지의 프로젝트 사진·고객사 작업물을 복제하지 않았다. 유리 면과 금속 리본의 추상 장면을 새로 생성했다. 생성 이미지는 실제 회사 공간이나 고객 프로젝트를 표현한 사진이 아니다.

## 디자인 규칙

- 흰 배경 `#fff`, 주 텍스트 `#111`, 밝은 섹션 `#eaeae5`. 이미지의 코발트·청록·호박빛 외에 별도 강조색을 늘리지 않는다.
- Wanted Sans. 큰 제목은 700, 본문은 400. 영문 히어로는 `12.8cqw`, 주요 본문은 `4.445cqw`로 360px 표시 폭에서 약 16px를 유지한다.
- 기준 폭 720 CSS px, 출력 2배. 좌우 여백 6cqw. 전체 높이는 내용에 맞춰 늘린다.
- 3장의 프레임을 -10°, -4°, +4°로 겹친다. 겹침은 히어로 안에 한정하고 채용 본문은 기울이지 않는다.
- 제목 ‘Your next / perspective.’와 ‘브랜드의 다음을, 당신의 시선으로.’는 짧은 영문 메시지와 구체적인 한국어 역할 소개를 연결한다.
- 상단 로고 → 영문 제목 → 생성 이미지 → 한국어 역할과 조건 → 회사 관점 → 업무 → 검은 자격요건 영역 → 근무조건 → 실제 사무실·복지 → 지원 안내 순서다.
- 업무·자격요건·근무조건·복지·지원 정보는 같은 회차의 `Sections.jsx`를 재사용한다. 새 컨셉 때문에 채용 사실을 추가하거나 바꾸지 않는다.
- 생성 이미지는 회차별 디자인의 장식 자산이며 텍스트는 React로 조판한다. 이미지에 채용 텍스트를 생성하지 않는다.
- 날짜·접수기간은 이미지에 넣지 않고 기존 지원 방법 규칙을 따른다.

## 검수

360·390·720px에서 본문 가독성과 넘침을 확인한다. 최종 PNG에서 프레임 겹침, 제목과 이미지 간격, 한글 어절·역명 줄바꿈, 검은 영역의 대비를 확인한다. 기존 A·B 및 과거 공고에 스타일이 적용되지 않는지 함께 확인한다.
